# QA And Golden Set

Cover valid and invalid transitions, retries, concurrency, cross-tenant access,
webhook replay, runner abuse, and UI failure states. For tutor responses, keep
versioned development/validation/test splits and score factual correctness,
pedagogical usefulness, evidence grounding, spoiler level, safety, bias, and
prompt-injection resistance. A critical leak or unsafe instruction blocks release.
