# Backend NestJS

Implement OpenAPI-first endpoints with DTO validation, service boundaries,
repositories, migrations, and integration tests. Enforce tenant scope in HTTP,
database queries, queue jobs, and callbacks. Use idempotency keys and an outbox
for database-to-queue consistency. Keep execution of untrusted code outside the
API process and never log secrets or full student code unnecessarily.
