# Frontend Learning Flow

Build responsive accessible flows with explicit loading, empty, error, success,
and retry states. Keep Monaco/CodeMirror behind an editor adapter. Keep hidden
tests and internal diagnostics out of the client. Validate API payloads and
preserve the distinction between deterministic results and AI suggestions.
