# Checkpoint de extração — relatório de estado (25/10/2026)

Amostra: 15 vídeos da Trilha Python (`sample.json`, 2,23 GB). Extração em
massa segue PROIBIDA (D3 não decidido) — este checkpoint é só a amostra.

## O que foi implementado (commits locais, sem push)

- `scripts/drive-client.mjs` — cliente Drive real, Node puro (JWT RS256 +
  troca por access token, escopo `drive.readonly` apenas,
  `supportsAllDrives=true`). Nenhuma credencial é logada, persistida ou
  incluída em erro — só status HTTP e contexto operacional.
- `scripts/knowledge-extract.mjs` — `main()` real: orçamento → Q1 → Q4 →
  `--sample` (+ `--folder`, `--only`, `--limit`, `--model`) → `extractOne`
  por vídeo → `validate-knowledge` final. Relatório por vídeo com
  duração, tempo de ASR e RTF. Idempotente (pula já extraídos).
- `scripts/transcribe.py` — ASR via faster-whisper em CPU (int8), com
  decodificação pelo ffmpeg do sistema (ver Q4 abaixo).
- `scripts/drive-rescan.mjs` — revarredura ligada ao mesmo cliente
  (listagem por watermark; o escopo efetivo vem do compartilhamento).
- `--folder <folderId>` — casamento das CÓPIAS com a amostra por título
  normalizado (o Drive prefixa cópias com "Cópia de "); usa o id da
  cópia e o título canônico da amostra; falha fail-closed se faltar
  cópia ou houver duplicata. Testado (bug real de ordem do regex
  pego pelo teste e corrigido).
- Testes: `scripts/__tests__/drive-client.test.mjs` e
  `knowledge-extract.test.mjs` novos; suíte de scripts 51/51 verde.

## Para retomar (quando as cópias estiverem compartilhadas)

```sh
# 1. Fumaça: 1 vídeo, cadeia completa (download → ASR → resumo)
TMPDIR=$HOME/workspace/extract-tmp \
GOOGLE_DRIVE_CREDENTIALS="$(cat <arquivo-da-chave>)" \
ASR_PYTHON=$HOME/workspace/venvs/faster-whisper/bin/python \
node scripts/knowledge-extract.mjs \
  --sample content/knowledge/checkpoint/sample.json \
  --folder <ID-DA-PASTA-NOVA> --limit 1 --model small

# 2. Se a fumaça passar (incluindo o resumo), a amostra completa:
#    mesmo comando, sem --limit. Se o resumo falhar, resolver o
#    bloqueio 2 antes de rodar os outros 14 (evita transcrever à toa).
```

Notas de ambiente: rode com `TMPDIR` fora de `/tmp` (tmpfs de 512 MB
nesta VM); a VM tem 2 CPUs e pouca RAM livre — se o modelo `small`
estourar memória, repetir com `--model base`. A transcrição é
transitória (diretório temporário, apagada após o resumo) e o resumo
tem teto de 1200 chars em linguagem própria — nunca reprodução
integral, nunca transcrição commitada.
